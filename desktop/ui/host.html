Reaching this room from outside

Works on any network, including guest Wi-Fi and connections you don’t administer — it dials out, so nothing needs a forwarded port or a firewall rule. Only signalling goes through Cloudflare; audio and video still go straight between you. The address changes each time you switch it on, so send the new link each session.

Only useful on a router you control. On guest or office Wi-Fi there is nothing to ask, and it cannot help behind carrier-grade NAT either. Use the tunnel above instead.

If someone cannot connect

Windows Firewall is set up by the installer, but a third-party antivirus with its own firewall — Avast, Kaspersky, Norton — blocks incoming connections independently and has to be allowed separately. That is the usual cause when the address is right and nothing loads.
